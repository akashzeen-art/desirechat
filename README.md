# Spark (FlirtAI)

Chat & voice flirting app — pick your vibe, choose who to flirt with, and talk.

## Run

```bash
cd ai/talktohistory/frontend
npm install
cp .env.example .env
# add your OpenAI key to .env
npm run dev
```

Open http://localhost:5173

See `ai/talktohistory/README.md` for more details.
